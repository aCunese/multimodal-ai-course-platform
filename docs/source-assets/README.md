# 原始素材归档说明

这里存放的是项目早期导入或生成的原始参考素材，不直接作为运行时代码引用。

## 目录职责

- `high-fidelity-originals/`
  - 最初导入的 6 张高保真原型图原文件，保留原命名用于溯源。
- `stitch-2/`
  - 历史静态 HTML 参考稿与其设计说明，主要用于回看结构和样式探索过程。

## 与 `ui-reference/` 的区别

- `docs/ui-reference/`
  - 面向当前开发的整理版参考区，文件命名更清晰，适合直接对照实现。
- `docs/source-assets/`
  - 面向存档和追溯，保留原始来源与历史稿，不建议在业务代码中直接硬编码引用。
