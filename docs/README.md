# 文档总览

`docs/` 负责承接项目里的所有非运行时代资料，目标是把“开发说明”“视觉参考”“原始素材”“课程交付材料”分开管理。

## 目录职责

- `architecture/`
  - 架构基线、目录规范、整理说明等长期有效的项目文档。
- `ui-reference/`
  - 当前开发直接使用的高保真参考图、HTML 结构整理稿与 UI 对照说明。
- `source-assets/`
  - 原始导入素材和历史参考稿存档，保留来源信息，默认不直接用于业务代码。
- `course-materials/`
  - 报告模板、课程提交相关资料。
- `superpowers/`
  - 过程性计划、协作记录和阶段性实施说明。

## 使用原则

- 需要“直接照着开发”的内容优先放 `ui-reference/`。
- 需要“保留原始来源”的内容放 `source-assets/`。
- 需要“说明项目为什么这样组织”的内容放 `architecture/`。
- 不要把图片参考稿、临时说明、课程模板继续堆回项目根目录。
