# UI 实现对照审计

日期：2026-06-05

## 审计结论

当前 `web/` 中的前端演示版已经和 `docs/ui-reference/high-fidelity/` 的 6 张原型图完成了“页面级结构对齐”：

- 左侧固定导航、顶部工具条、页面标题区已经统一。
- 6 个页面的模块职责、主要卡片分区和内容顺序已经对应上原型图。
- 首页 Hero、模块卡片、统计卡片、历史表格的层级关系已经重建。
- 图像识别、情感分析、文案生成、博物馆图像理解、历史记录页都已有对应的主操作区和结果区。

可以认为当前状态已经不是“没有 UI 对应”，而是“已搭出统一演示版，细节仍需继续精修”。

### 首页总览

- 有统一中文品牌名 `多模态 AI 课程成果平台`。
- 有深色 Hero 区、双按钮、四个模块入口卡片、四个统计区块和最近记录表格。

### 图像识别

- 有上传区、识别结果区、置信度环图、分类概率分布和模型信息。

### 情感分析

- 有文本输入区、情感结果卡、关键词分析、情感强度区和分析状态区。

### 文案生成

- 有主题输入、风格选择、类型切换、生成结果列表和策略说明区。

### 博物馆图像识别 / 描述

- 有图像样例、来源识别结果、候选馆藏列表、标签和数据说明。

### 历史记录与项目说明

- 有筛选区、历史表格、模块说明和项目整理结果说明。

## 与原型图仍有差距的部分

### 视觉精度

- 当前实现优先保证结构与信息层级一致，暂未逐像素还原原型图中的每个小图标、阴影与边距。

### 交互真实性

- 上传、分析、生成、筛选仍是演示级静态界面，尚未接真实接口。

### 局部素材

- 原型中的个别示例图和复杂图表效果，当前以可维护的 mock 组件和本地素材替代，没有做 1:1 位图复刻。

## 本次素材归位结果

原先位于工作区根目录的散落运行时图片已经迁入：

```text
web/src/assets/
├── branding/
├── hero/
└── illustrations/
```

这样可以区分：

- `docs/ui-reference/`
  - 只放原型和参考稿。
- `web/src/assets/`
  - 只放运行时真正会被前端引用的图片。

## 后续建议

1. 接入真实上传与推理接口，把页面从 mock 演示升级成可操作 demo。
2. 对照高保真图继续微调间距、字体大小、图标细节和表格密度。
3. 如果后续再新增页面或素材，优先放入 `docs/ui-reference/` 或 `web/src/assets/` 对应位置，不要重新散落到根目录。
