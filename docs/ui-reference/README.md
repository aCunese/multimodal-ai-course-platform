# UI 参考

这里保留项目的 6 张高保真页面参考图，用来展示整体视觉风格和主要交互布局。

## 页面映射

| 页面 | 文件 | 说明 |
|---|---|---|
| 首页总览 | `high-fidelity/dashboard-overview.png` | 模块入口、运行时状态和最近记录 |
| 图像识别 | `high-fidelity/image-recognition.png` | 图片上传、分类结果与概率分布 |
| 情感分析 | `high-fidelity/sentiment-analysis.png` | 文本输入、情绪判断与关键词分析 |
| 文案生成 | `high-fidelity/text-generation.png` | 主题输入、风格选择与生成结果 |
| 博物馆图像理解 | `high-fidelity/museum-vision.png` | 馆藏识别、图像描述与标签导出 |
| 历史记录 | `high-fidelity/history-and-project.png` | 记录检索、筛选、分页和导出 |

## 使用说明

- 这些图片用于快速理解页面信息架构和视觉层级。
- 生产代码以 `web/` 中的实现为准，不直接从图片生成页面。
- 如果需要更系统的实现说明，配合 `../architecture/technical-overview.md` 一起阅读。
